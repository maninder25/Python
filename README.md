# Day 1 — Python Core Strengthening 🐍

## 📌 Overview

Day 1 focused on strengthening Python fundamentals through hands-on coding practice.

The goal was to build confidence with Python syntax, conditional logic, loops, user input, type conversion, strings, and basic problem-solving.

Instead of only studying theory, I solved multiple programming problems and built a **Student Result Management System** as the Day 1 mini project.

By the end of Day 1, I practiced:

* Variables and data types
* Arithmetic, comparison, and logical operators
* `if`, `elif`, and `else`
* `for` and `while` loops
* `break`
* User input with `input()`

* String manipulation
* F-strings
* Basic problem-solving
* Conditional expressions
* Basic edge-case handling
